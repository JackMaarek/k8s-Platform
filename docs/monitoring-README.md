## Values files

| File | Scope |
|---|---|
| `prometheus-values.yaml` | Prometheus, Alertmanager, node-exporter, kube-state-metrics |
| `grafana-values.yaml` | Grafana subchart — sidecar, persistence, plugins |
| `loki-values.yaml` | Loki — retention, storage, query limits |
| `promtail-values.yaml` | Promtail — log pipeline, label extraction |
| `opencost-values.yaml` | OpenCost — AWS pricing, GPU cost tracking |

Both `prometheus-values.yaml` and `grafana-values.yaml` are loaded by the prometheus ApplicationSet
via the multi-source pattern — they are kept separate to enforce SRP.

## Dashboards

Dashboards are loaded by the Grafana `k8s-sidecar` container which watches for ConfigMaps
with the label `grafana_dashboard: "1"`. No Grafana restart required.

Dashboard ConfigMaps live in `kubernetes/manifests/monitoring/dashboards/` organised by folder:

```
dashboards/
  infrastructure/    ← cluster, nodes, namespaces
  platform/          ← ArgoCD, Istio, Kyverno, ESO
  ml/                ← ML workloads (generated by ml-batch-job chart when enabled)
```

To add a dashboard:
1. Export JSON from Grafana UI
2. Create a ConfigMap in the appropriate subfolder
3. Add label `grafana_dashboard: "1"` and annotation `k8s-sidecar-target-directory: "<folder>"`
4. Commit — Grafana hot-loads it within 30s

## Datasources

Datasource ConfigMaps live in `kubernetes/manifests/monitoring/datasources/`.
The Grafana sidecar hot-loads them on change — no restart required.

Current datasources:
- Prometheus (default)
- Loki

## Access

```bash
# Grafana — port-forward
kubectl port-forward svc/prometheus-grafana -n monitoring 3000:80
# http://localhost:3000 — admin / (see secret below)

# Get Grafana admin password
kubectl get secret prometheus-grafana -n monitoring \
  -o jsonpath="{.data.admin-password}" | base64 -d

# Prometheus UI
kubectl port-forward svc/prometheus-kube-prometheus-prometheus -n monitoring 9090:9090

# Alertmanager UI
kubectl port-forward svc/prometheus-kube-prometheus-alertmanager -n monitoring 9093:9093

# OpenCost UI
kubectl port-forward svc/opencost -n finops 9090:9090
```

## GPU cost tracking

OpenCost is configured with AWS pricing integration for `eu-west-3`. GPU node costs
(g4dn.xlarge) are tracked via the `nvidia.com/gpu` resource. SPOT pricing is approximated
at 70% of on-demand (OpenCost default heuristic).

GPU nodes scale to zero between ML runs — OpenCost reports zero GPU cost when idle.

---

## Istio integration

The monitoring namespace has `istio-injection: disabled` — Prometheus Jobs cannot terminate
cleanly with an Istio sidecar. This is intentional and documented in `kubernetes/namespaces/monitoring-namespace.yaml`.

Prometheus scrapes Istio metrics via ServiceMonitors in `istio-system` namespace using
cross-namespace scraping (`namespaceSelector: any: true`).

## Retention and storage

| Component | Retention | Storage |
|---|---|---|
| Prometheus | 7 days | 20Gi PVC |
| Loki | 7 days (168h) | 20Gi PVC |
| Grafana | — | 10Gi PVC (dashboards + settings) |

Adjust retention in the respective values files. Storage class defaults to `gp3` (EKS default).
